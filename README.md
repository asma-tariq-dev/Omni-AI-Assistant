# 🤖 Omni AI Assistant

A multimodal GenAI assistant built with Groq LLM, Streamlit, voice processing and AI image generation.

## Features
- Text AI chat
- Coding assistant mode
- Voice conversation
- Text-to-speech responses
- AI image generation

## Run
```bash
pip install -r requirements.txt
streamlit run app.py
```

Create `.env`:
```
GROQ_API_KEY=your_key_here
MODEL=openai/gpt-oss-120b
```
